Apply [COMMON](COMMON.md). Use the real selected **MythicSim Rust or Go** engine. P4–P6 still require real spatial world/native causality.

## Frozen reference

Use the exact available saved external MythicSim report and authenticated original request or matching Settings UI where it exists; never reconstruct a missing material field by guessing. If no report exists, build a documented, playable native-legal level-appropriate reference using available sources and run the real native engine to pin its arithmetic mean. Mark this source `native_generated_msim_reference`, never `external_saved_report`. Both paths pin the full runnable request, provenance, encounter and numeric score. No second external MythicSim accuracy audit or 10,000-fight replay is required. A missing actual executable reference remains BLOCKED.

## P7.1 — reproducible fixed reference

On the frozen reference build, run **one real 1,000-independent-fight stochastic native sample**, requiring arithmetic `mean_DPS >= 0.99 × pinned_reference_DPS` under compatible settings. Reuse the exact authentic native-generated reference receipt when its build, engine, encounter, RNG/scoring and 1,000 independent stochastic fights already match. No second native replay or gsim-2D reproduction is required. Record provenance, full request/output and frozen identity; no fake/approximate score.

## P7.2 / P7.3 / P7.4 — real single-axis changed candidate

These are **three separately countable diagnostic search capabilities** on the same frozen reference. The optimizer must actually generate a **distinct native-legal changed candidate**, keeping the other two axes fixed, pay the selected real native scorer and retain the changed axis, full build, finite comparable objective and engine/config identity:
- **P7.2:** change rotation/APL only; freeze reference talents and gear.
- **P7.3:** change talent allocation only; freeze reference rotation/APL and gear.
- **P7.4:** change equipment/enchants only; freeze reference talents and rotation/APL.

Where no legal changed alternative exists, report unsupported/BLOCKED, not PASS. A refused/invalid/unexecuted candidate or unchanged reference is not PASS. **No independent 300s cold deadline, 1,000-fight holdout, 99%-of-reference performance floor or separate 2D receipt** for these three axis diagnostics. They do not assert an axis optimum and their deterministic balanced-RNG score is **not** a stochastic prior mean.

## P7.5 — independent joint optimizer and stochastic non-inferiority

Run a separate **300 actual wall-second, cold, genuinely paid** source-legal joint **gear × talents × rotation/APL** search. Do not seed its candidate frontier with the saved reference or any P7.1–P7.4 winner. Record real distinct paid candidates, actual winner and config/engine/encounter identity. Freeze the winner **before** a separate **1,000-independent-fight stochastic native holdout**; compare its arithmetic mean DPS against

`mean_DPS_P7.5 >= 0.93 × max(pinned_reference_DPS, strongest_accepted_compatible_stochastic_prior_mean_if_any)`.

A prior qualifies only when its actual **accepted compatible stochastic** native mean exists and shares pinned encounter/source/engine/config semantics; deterministic P7.2–P7.4 scores are not promoted to holdout comparators. **Absent optional axis stochastic holdouts do not BLOCK P7.5**. Use balanced deterministic small-repeat scoring for candidate comparison, stochastic RNG for the 1,000-fight holdout; no confidence-bound floor, last-search-step timestamp, fabricated comparison, or 2D-specific parity gate.
