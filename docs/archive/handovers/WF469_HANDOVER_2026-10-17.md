# WF469 — source-aligned generic P1 checker and optimizer admission

## What changed

- P1 gets LEGAL / CONDITIONAL / PASSIVE / ILLEGAL / UNRESOLVED from the existing canonical source frontier and a verified, class-neutral client spellbook snapshot where available. A spell-index entry or a low level number alone no longer makes a rune/passive/obsolete entry a castable legal action.
- Selection of independently sourced spellbook evidence is by schema, class, level coverage and canonical source-index digest; closest matching checkpoint is chosen deterministically.
- A production-supported, typed effect with a *documented* approximation remains an APL candidate. Unknown effect types and unknown semantic flags stay rejected. This restores Entangling Roots, Rip, and Regrowth to generic candidate search without claiming their fidelity is perfect.
- Target stat/debuff probes now use production's sourced target metadata, and target-scoped combo points are set to a valid resource level for a legitimate finisher.
- Regression suite no longer assumes a full production baseline is missing: it verifies the live path.
