# WF470 — P1 scope fit + Druid L20 real source/runtime coverage

## User-approved change

P1 checks only damage, buff/debuff and CC (including stealth). Downranking is excluded: only the highest **source-legal and checkpoint-learned** rank in each family is checked. Existing PROCESS P2–P7 unchanged. Unknown effect scope for missing legal action is a named FAIL, not silently excluded.

## Mechanisms

- Generic source scope lookup: source-index tooltip where present, source-role observations ingested into **canonical SQLite**, provenance-anchored to the same source-index record; the versioned JSON is input evidence, never a runtime whitelist.
- Exclude non-combat, situational utility from P1 with the already versioned source spellbook's explicit context exclusions; do not treat all missing IDs as abilities.
- Rank reduction occurs **after** source legality; tied same-family same-rank source IDs fail ambiguous rather than being hidden.
- Actual queued swing probe now supplies canonical IR auto attack and observes the next swing's `Damage`, not just a queued event.
- Live P1 resolves its build as-of from explicit `WOW_FOREVER_BUILD_AS_OF`, or today's date for the CLI; report includes build identity.
- Reuse existing checked external source-observation ingestors, already present in baseline, for Maul R2 and Bash R1. Neither spell's values are invented or hardcoded into the P1 gate.
